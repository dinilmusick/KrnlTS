# Exhibit 3: Entity Base & State Management

## Concept
Demonstrates the creation of Krnl entities and the usage of the State Manager component.

## Visual Theme
Dark Fantasy / Stone of Destiny.

## Content
- **Entity Creation**: `new krnlEntityBase(name)`
- **State Management**: `stateManager.createState`, `setStateValue`, `getStateValue`.

## Usage
Open `index.html` served via `exhbtSrv`.
