# Exhibit 1: Base Concepts & Data Factory

## Concept
Demonstrates the foundational data types and factory patterns for creating standardized Krnl messages.

## Visual Theme
Dark Fantasy / Alchemy Lab.

## Content
- **Enums**: `createEnum` (Immutable Types)
- **Data Factory**: `krnlDataFactory` (Standardized Object Creation)
  - `audio`: Stream configuration.
  - `control`: Signal values.
  - `trigger`: Discrete events.

## Usage
Open `index.html` served via `exhbtSrv`.
