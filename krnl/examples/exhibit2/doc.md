# Exhibit 2: System Errors & Handling

## Concept
Demonstrates the system-wide error definitions and the integer-coded error transport mechanism.

## Visual Theme
Dark Fantasy / Executioner's Block.

## Content
- **Error Codes**: `krnlErrorCodes` (Integer identifiers)
- **Typed Errors**: `krnlError` (Cross-platform error wrapper)

## Usage
Open `index.html` served via `exhbtSrv`.
