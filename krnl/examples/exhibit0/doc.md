# Exhibit 0: Core Function Atoms

## Concept
Demonstrates the fundamental recursive operators that underpin the Krnl system's logic processing.

## Visual Theme
Dark Fantasy / Math Grimoire.

## Content
- **R_Map**: Transformation of sets. $A \xrightarrow{f} B$
- **R_Filter**: Subset selection. $A' \subseteq A$
- **R_Reduce**: Dimensionality reduction / accumulation. $\sum A 	o S$
