# Krnl Base Handbook

Welcome to the **Krnl Base Handbook**. This guide covers the foundational principles, entities, and libraries that power the entire Krnl ecosystem.

## 📚 Contents
- **[Getting Started](getting_started.md)**: A high-level architectural guide for building entities and logic.
- **[Uniform Networking](networking.md)**: CRITICAL guide on using `commComponent` for inter-system communication.
- **[API Reference](api_reference.md)**: Detailed specification of base classes and utility libraries.
- **[Design Principles](../../GEMINI.md#viii-framework-design-principles)**: The "Golden Rules" of the Krnl framework.

## 🎯 Purpose
The `krnlBase` handbook is designed to ensure that all developers, regardless of the system they are working on, follow the same core patterns for state management, communication, and lifecycle control.
