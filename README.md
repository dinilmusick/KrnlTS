# KrnlTS Framework

KrnlTS is the core protocol library for building distributed atomic entities, unified HTTP/WS/MCP/ACP servers, and agentic orchestration endpoints.

## 🚀 How to Build & Run Examples

### Build Framework:
```bash
# In the KrnlTS root:
pnpm run build
```

### Run E2E AI Calculator Example:
```bash
npx tsx examples/example1/run_ai_calculator.ts
```
