# Test New Features

This example is a comprehensive integration test suite for the newly introduced KrnlTS primitives:
- `KrnlResult`
- `ObjectKit`
- `AsyncKit`
- `StringKit`
- `CacheKit`
- `KrnlFS`
- `KrnlEnv`
- `KrnlShell`
- `KrnlHTTP`
- `GitManager`

## Running the tests

To run the tests:
```bash
node run_test.js
```
